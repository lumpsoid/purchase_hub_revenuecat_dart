# Migration: SDK log level via `RevenueCatConfiguration.logLevel`

`RevenueCatConfiguration` now has an optional `logLevel` field controlling the
verbosity of the RevenueCat SDK's own logging. When set, the adapter calls
`Purchases.setLogLevel` for you during `initialize()`, before configuring the
SDK — so the configuration step itself is logged.

**Why:** setting the log level was the one remaining reason a consumer might
still reach for `Purchases.setLogLevel` directly, forcing a `purchases_flutter`
import purely for logging setup. Folding it into `RevenueCatConfiguration` keeps
the SDK fully encapsulated behind this package.

This is a **non-breaking, additive change**. `logLevel` defaults to `null`,
which leaves the SDK's default log level untouched.

## Before

```dart
import 'package:purchases_flutter/purchases_flutter.dart';
import 'package:purchase_hub_revenuecat/purchase_hub_revenuecat.dart';

await Purchases.setLogLevel(LogLevel.debug);

final initializer = RevenueCatInitializer(
  const RevenueCatConfiguration(apiKey: 'your_api_key'),
);
```

## After

```dart
// No purchases_flutter import needed.
import 'package:purchase_hub_revenuecat/purchase_hub_revenuecat.dart';

final initializer = RevenueCatInitializer(
  const RevenueCatConfiguration(
    apiKey: 'your_api_key',
    logLevel: RevenueCatLogLevel.debug,
  ),
);
```

The adapter sets the log level while handling `initialize()`; you no longer call
`Purchases.setLogLevel` yourself.

## Enum mapping

`RevenueCatLogLevel` mirrors RevenueCat's `LogLevel`, ordered from most to least
verbose.

| RevenueCat SDK      | This package                 |
| ------------------- | ---------------------------- |
| `LogLevel.verbose`  | `RevenueCatLogLevel.verbose` |
| `LogLevel.debug`    | `RevenueCatLogLevel.debug`   |
| `LogLevel.info`     | `RevenueCatLogLevel.info`    |
| `LogLevel.warn`     | `RevenueCatLogLevel.warn`    |
| `LogLevel.error`    | `RevenueCatLogLevel.error`   |

> Leave `logLevel` as `null` (the default) to keep the SDK's own default log
> level. The adapter only calls `Purchases.setLogLevel` when a level is set.
